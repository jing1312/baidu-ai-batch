# baidu-ai-batch · 百度网盘视频 AI PPT/笔记/讲稿自动导出

> 网盘里的网课视频，AI 能自动生成课件 PPT、讲稿和笔记——但一次只能手动点一节，而且要点开视频、触发 AI 生成、等它跑完、再点导出。
> 这个工具让浏览器自己干这些活：153 节视频，挂机跑完就都齐了。

**实际战果**：因为上课喜欢划水，但考试至关重要——我用它处理了 4 门专业课共 153 节视频，自动生成并导出 **146 份 AI 课件 PPT、122 份讲稿、55+ 份笔记**，全程无人值守。而手动完成同样的事，需要对屏幕重复 450+ 次「打开 → 触发 → 等待 → 导出」，至少盯一整天。

---

## 为什么要写这个

网盘 AI 对每节视频的课件、讲稿、笔记都是**按需生成**的，不是视频自带的：

- 每节都要：打开视频 → 切到「课件/文稿/笔记」标签 → 触发 AI 生成 → 等服务端跑完（几秒到几分钟）→ 才能导出
- 没有批量入口，153 节视频就得手动重复 153 次，全程盯着屏幕等
- 而且 AI 生成有额度限制，功能也可能随时调整——不赶紧导到本地，生成过的东西说没就没了

所以写了这套脚本：打开、触发、等待、导出，全部自动，跑完收工。

## 能干嘛

| 任务 | 输入 | 输出 |
|------|------|------|
| `export-ppt` | 视频清单 | 触发 AI 课件生成 → 点导出，PPT 自动存到网盘视频所在文件夹 |
| `extract-manuscript` | 视频清单 | 触发 AI 讲稿生成 → 等生成完 → 抓取存为本地 TXT |
| `export-notes` | 视频清单 | 触发「图文笔记」生成（等 1-5 分钟）→ 点导出（PDF 存网盘）+ 本地 TXT 备份 |

跑起来就不用管了：脚本自己开视频页、点生成、轮询等结果、点导出，你该干嘛干嘛。

## 踩过的坑

**1. 复用浏览器登录态，不用逆向**
命令直接发给已登录的浏览器，网盘负责生成，脚本只负责点。门槛就一个：浏览器开个调试端口。

**2. 新标签页干活，不打扰你上网**
每个任务都在新建的标签页里完成，做完就关。脚本跑批的时候你照常刷网盘、看文档，互不干扰。

**3. 有两个「导出 PPT」，点错的那个 100% 失败**
AI 聊天窗口里的快捷指令会调错 API，必挂；真正有效的是课件区右上角的导出图标（`.ai-course__export-container`）。早期版本被坑了两轮才发现。

**4. 笔记在 iframe 里读不到？把 iframe 单独开个标签页**
笔记内容渲染在 `#noteIframe` 里，跨域读不了。解法很简单：把 iframe 的 URL 在新标签页打开，它自己变成顶层页面，DOM 随便读。

**5. 断点续传，断了也不慌**
PPT 进度实时写进 `state.json`，中途超时、断连，重跑只处理没完成的；讲稿/笔记按本地文件是否存在自动跳过，`--force` 强制重跑。

**6. 识别「假成功」**
AI 生成失败时页面会留一段 85~91 字的占位模板，看起来像生成好了。脚本按字数阈值判断，占位的不算数，不会存成空壳文件。

**7. 串行执行是故意的**
早期开 20 路并发狂点，PPT 失败率飙到 80%；改成串行 + 等元素出现，单节成功率接近 100%。批量任务不是跑得快就行，是别把平台惹毛了。

## 适合谁用

- 🎓 **学生**：一学期 150 节网课，期末前把 AI 课件/讲稿/笔记一键归档，复习时本地搜
- 👩‍🏫 **讲师 / UP 主**：录课视频批量出 PPT + 讲稿，做讲义、做字幕稿
- 📚 **知识管理**：纪录片、播客、会议录像让网盘 AI 批量生成笔记，攒成自己的资料库

## 还有油猴插件版（不用装 Node）

不想装环境？项目还带了一个油猴脚本：`userscript/baidu-ai-batch.user.js`，浏览器里点几下就能用。

- 装 [Tampermonkey](https://www.tampermonkey.net/)（或暴力猴）→ 新建脚本，把文件内容粘进去保存
- 打开网盘**文件列表页**（视频所在目录），右下角面板点「收集本目录视频」
- 点「开始跑批」，脚本会自己一集一集打开视频：导 PPT → 下讲稿 → 生成笔记并导出，全部弄完自动跳下一节，进度存在浏览器里（关掉重开也不丢）
- 也可以在任意**视频播放页**打开面板，只处理当前这一节

原理和 Node 版一样，只是把「脚本控制浏览器」换成了「脚本就是页面的一部分」，所以不需要调试端口，代价是油猴脚本拿不到 Node 版的串行节奏控制，遇到限流时可能失败多一些，失败的话重跑会自动跳过已完成的部分。

## 快速开始

需要：Node.js ≥ 18，一个以调试模式启动的 Edge / Chrome（并登录百度网盘）。

### 1. 启动调试浏览器

```bash
msedge --remote-debugging-port=9222
# 或 chrome --remote-debugging-port=9222
```

> 调试模式的浏览器和日常浏览器是分开的，需要在这里重新登录一次网盘，之后可以一直挂着。

### 2. 安装配置

```bash
npm install
cp config.example.json config.json   # Windows: copy config.example.json config.json
```

改 `config.json`，一般只动两处：

```jsonc
{
  "videoFolder": "/我的资源/课程视频/",  // ← 视频在网盘哪个目录
  "skipList": []                         // ← 要跳过的视频（比如黑屏、损坏的）
}
```

用网盘 API 自动生成视频清单：

```bash
node bin/list-files.cjs
```

### 3. 开跑

```bash
node bin/export-ppt.cjs          # ① 批量导出 AI 课件 PPT
node bin/extract-manuscript.cjs  # ② 批量提取 AI 讲稿 → 本地 TXT
node bin/export-notes.cjs        # ③ 批量生成并导出 AI 笔记（--force 重跑）
```

三个任务互相独立，可以分开跑、随时中断、随时续跑。跑完 `output/` 里是全部讲稿和笔记，PPT 在网盘视频目录里。

## 配置项

| 字段 | 说明 | 默认 |
|------|------|------|
| `host` / `port` | 浏览器调试地址 | `127.0.0.1:9222` |
| `panBase` | 网盘域名 | `https://pan.baidu.com` |
| `videoFolder` | 网盘内视频目录，以 `/` 结尾 | `/我的资源/课程视频/` |
| `listFile` | 视频清单文件 | `video-list.txt` |
| `stateFile` | PPT 进度存档（断点续传用） | `state.json` |
| `outputDir` | 讲稿/笔记本地输出目录 | `output/` |
| `skipList` | 跳过的视频名数组 | `[]` |
| `minContentLen` | 判定内容有效的字数阈值（防「假成功」） | `100` |

> `config.json`、`state.json`、`output/` 已加入 `.gitignore`，不会把个人配置和文件传上去。

## 原理

```
node bin/*.cjs
   │  HTTP  ┌─────────────────────────┐
   ├──────► │ 浏览器 CDP 接口 :9222   │
   │        │  (msedge --remote-...)  │
   │  WS    └───────────┬─────────────┘
   └────────────────────┘
        新标签页 → 打开视频页
        → 切「课件/文稿/笔记」标签 → 触发 AI 生成
        → 轮询等服务端生成完（内容出现 / 导出按钮出现）
        → 点导出 / 抓 DOM → 收文件 → 关标签页
```

只依赖 `ws` 一个包，没有浏览器内核、没有插件、没有后台服务。

## 已知问题

- 课件/讲稿/笔记是**服务端生成**的：某节视频要是持续为空或只有占位模板，基本是服务端生成失败，脚本重跑也没用，得去网页端手动重试那一节
- 每次点 PPT 导出，网盘里都会多一个带时间戳的新文件，重复跑会积累重复文件，自己记得清理
- 串行执行是故意的（见「踩过的坑」第 7 条），别自己改成并发，会触发限流

